Nothing opened? You probably need Blockpad first

  1. Download Blockpad for Windows
  2. Install it. Windows: run Blockpad-Setup.exe (if it says “protected your PC”: More info, then Run anyway). macOS: unzip and right-click → Open. Linux: extract and run Blockpad.
  3. Come back to this page and press Open in Blockpad, or open Blockpad and paste the link into it.

Anyone with this link can join, so keep it between people you trust.

Join on your phone

Open the Blockpad web app and join right here, no install needed. On iPhone use Safari, then Share → Add to Home Screen to keep it. On Android you can also install the app from the home page.

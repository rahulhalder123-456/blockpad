How sharing works

  1. Press Share on a page in Blockpad and copy the Can edit or View only link.
  2. Send it by WhatsApp, Telegram, email, anything.
  3. They click it. If they have Blockpad it opens and asks to join. If not, this website helps them install it first.
  4. You edit together. You see who is online and which block they are on. Everyone keeps a full copy, so it also works offline.

The page content never goes through this website. The link carries only the access secrets, after the #, which browsers do not send to any server.

Questions

Does it cost anything or need an account?

No. There is no account, no cloud and nothing to subscribe to.

Where is my data?

In a single file in your user folder on your computer. Settings → Data shows the location and lets you move it.

Who can see what I share?

Only people who have your link. Anyone with the link can join, so send it only to people you trust. The View only link cannot change your page.

Does the other person need to be online?

You each keep your own copy. Changes sync whenever at least two people from the group are online at the same time.

Mac, Linux or phone?

Not yet. Blockpad is for Windows PCs for now.
